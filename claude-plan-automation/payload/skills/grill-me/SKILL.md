Don't assume. Think hard. Take your time. Interview me to align on a plan.

- Read the relevant code first, so you only ask what the code can't answer.
- Ask a few questions at a time, not a long list.
- Don't write or change any code until I approve the plan.
- When the questions are done, give me the plan in short, plain steps.
